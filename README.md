# flower-shop-javaee-ssm
鲜花在线商城 JavaEE SSM项目
B/S架构鲜花电商前台系统
技术栈：JavaEE、Spring+SpringMVC+MyBatis、MySQL、Tomcat、JSP

## 项目简介
实现鲜花商城前台业务：用户注册登录、商品浏览搜索、购物车、订单结算、模拟支付、个人中心信息与地址管理。

## 测试说明
本项目完成完整手工黑盒功能测试，编写测试计划、测试用例，对注册登录、购物车、订单支付等模块开展功能验证，对应开发文档第六章测试部分。
Selenium Web自动化为自学内容，理解元素定位、自动化测试思想，完整业务脚本还在练习完善中。
